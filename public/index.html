What is Diluvium?

The Diluvium Programming Language is a 100% backward-compatible extension of Lua with modern features like string interpolation, null coalescing, security enhancements, and more, without breaking legacy code.

🚀

Lightweight & Blazing Fast

The entire runtime is less than 1 MiB. Compiles to WebAssembly, x86_64, ARM64, and more, it launches instantly and runs anywhere.

Live Browser Runtime

Why Diluvium?

✨

Modern Syntax

String interpolation, null coalescing, and upcoming features like switch/match expressions—all while maintaining 100% backward compatibility with Lua.

🌍

Run Anywhere

Compiled to WebAssembly for browser execution, plus native runtimes for x86_64, ARM64, and more. One codebase, infinite platforms.

🔒

Constant Protection

Optional at-rest encryption of sensitive values in bytecode. Protect game assets, API keys, and configuration data from casual inspection.

🔄

Lua Compatible

Works seamlessly with existing Lua libraries and tools. Standard Lua code runs unmodified. Adopt new features gradually where they help most.

⚡

Zero Overhead

New syntax compiles to directly to bytecode for absolutely zero runtime performance impact.

📦

Tiny Footprint

Minimal runtime overhead, maximum portability. The entire WASM runtime is smaller than most JavaScript frameworks.

Language Features

String Interpolation
-- Old way
local name = "Alice"
local msg = "Hello, " .. name .. "!"

-- With Diluvium:
local msg = $"Hello, {name}!"

-- Complex expressions
print($"2 + 2 = {2 + 2}")
print($"User: {user.name ?? 'Guest'}")
Null Coalescing
-- Old way
local port = env.PORT
if port == nil then
    port = 8080
end

-- With Diluvium:
local port = env.PORT ?? 8080

-- Chain multiple fallbacks
local val = primary ?? secondary ?? 0
